# GAMEPLAY

Status: CANDIDATE IMPLEMENTED — 0.1.0-dev

## Vertical-slice loop
HOME → SOLO or ROOM → LOBBY → ROUND_ACTIVE → RESULT → REMATCH/LOBBY.

- 6 attempts per player.
- Same target word for every player in a room.
- The first solver becomes provisional winner and opens a 15-second finish window for remaining players.
- If all players complete earlier, results appear immediately.
- If nobody solves, the round ends once all players exhaust attempts.
- No daily limit; host can rematch indefinitely.

## Candidate numeric rules
- word lengths implemented: 4–8 + Random;
- room cap implemented: 8 players;
- these numeric ranges remain CANDIDATE until human validation.
